# Deploy Vercel

O projeto deve ser enviado ao GitHub com os arquivos da raiz preservados.

Arquivos obrigatórios na raiz:
- package.json
- vite.config.js
- vercel.json
- index.html
- src/
- public/

Vercel:
- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install
- Root Directory: ./

Não envie somente as pastas src/public: o Vite precisa dos arquivos da raiz.
